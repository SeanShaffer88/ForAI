| [NestJS](https://github.com/nestjs/nest) | Structured TypeScript server applications; assess dependency injection and framework overhead. |
| [Radix Primitives](https://github.com/radix-ui/primitives) | Unstyled React UI building blocks; validate accessibility in the finished composition. |
| [Floating UI](https://github.com/floating-ui/floating-ui) | Position tooltips, popovers and floating interfaces; keyboard and focus behavior still need design. |
