## Evidence and limits

Checked on October 23, 2026 in America/Chicago (the recorded UTC timestamps fall on October 24). All 200 additions received GitHub repository metadata checks and bounded README inspection. Twenty-four selected license excerpts were also inspected, particularly where metadata was missing or inconclusive. Eight repository moves were resolved to their current canonical names. The borgmatic entry links to its primary Forgejo repository; its GitHub repository is explicitly identified as a read-only mirror and its push timestamp describes that mirror. The primary page also returned HTTP 200 during this pass.

Discovery used Exa across 10 search angles and 100 requested result slots, including duplicates and irrelevant results that were filtered, followed by targeted primary-source reads. Additions were checked against all 992 pre-existing entries using normalized URLs, names, canonical repository URLs, repository IDs within the new batch, and a review of equivalent documentation/project entries. Existing overlaps were preserved; the 200 additions do not repeat existing projects merely under new documentation URLs.

Repository archive state, last reported push, detected license, README blob identifiers and selected license identifiers are recorded in the evidence file. Push dates are observations, not support guarantees. GitHub's license detector can miss dual licenses, exceptions or binary terms. License summaries below are discovery notes, not legal determinations; inspect the full terms for your selected version, dependencies and distribution. HTTP 200 confirms a successful source retrieval, not software safety.

No packages were installed or executed, and no full security/advisory, release, performance, compatibility, price or redistribution audit was performed. Hosted accounts and binary distributions remain distinct from repository source. Older or maintenance-mode projects are retained only with explicit caveats. Existing catalog research dates were not refreshed by this pass.

## Notable selection caveats

- Qwik, RxJS, Cap'n Proto and BorgBackup default branches describe prerelease or breaking work. Select versioned releases and matching documentation; Borg's current default README warns against production use of Borg2 beta.
- jqwik reports maintenance mode and an additional usage clause; CliWrap states additional terms of use; Verify distinguishes MIT source from an official-binary maintenance-fee policy.
- Windmill, Inngest, Duplicati and Defold need particular attention to custom, mixed or distribution-specific terms. FormatJS licensing was inspected only for its intl package.
- Four entries have reported pushes more than a year before this check: localForage, Sprache, DiskCache and HTTPie CLI. This is an activity signal, not proof that the projects are unusable.
