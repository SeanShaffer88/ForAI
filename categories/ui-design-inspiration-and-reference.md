# UI design inspiration and reference

[All categories](README.md) · [AI selection guide](../AGENTS.md) · [Full list and notes](../catalogs/design-inspiration-resources.md)

These services are discovery and visual-research references, not authoritative implementation specifications or permission to copy. Verify current access, source context, accessibility, and applicable usage rights before relying on examples. Entries were added from user-provided links on 2026-10-27; links and service details were not independently checked.

| Resource | Useful for / constraints |
|---|---|
| [Mobbin](https://mobbin.com/) | Browse mobile and web product interface examples for visual research; check access and usage terms before relying on or reusing materials. |
| [Page Flows](https://pageflows.com/) | Study product journeys and interaction flows as design references; validate details against the live product and respect access and reuse terms. |
| [Dribbble](https://dribbble.com/) | Discover and review designer portfolios and interface concepts; distinguish polished concepts from production-ready behavior and verify reuse rights. |
| [Behance](https://www.behance.net/) | Explore creative portfolios and design case studies; verify project context, attribution, and reuse rights. |
| [Collect UI](https://collectui.com/) | Find curated UI examples and visual references for interface design; treat examples as inspiration, not implementation specifications. |
| [SaaSFrame](https://www.saasframe.io/) | Explore SaaS interface references for product and web design; verify current access, context, and reuse permissions. |
| [Interface Index](https://interfaceindex.com/) | Use as an index of interface design references; confirm source context and rights before using any material. |
| [Pttrns](https://pttrns.com/) | Research mobile interface patterns and examples; check current coverage and terms before use. |
| [Awwwards](https://www.awwwards.com/) | Discover and evaluate showcased website design; assess accessibility, usability, and implementation constraints independently. |
| [SiteInspire](https://www.siteinspire.com/) | Browse website design examples and visual references; evaluate suitability and rights separately. |
