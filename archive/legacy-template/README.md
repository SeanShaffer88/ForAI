# Legacy template material — do not use as a resource reference

Everything in this folder is **archived template material, not catalog data**:

- `master-manifest.json`, the seven numbered category `manifest.json` files,
  and `manifests-resources.json` contain **generated placeholder entries**
  (for example "Utility #1" pointing at `github.com/topics/win32-tool-1`).
  Those resources do not exist. Do not cite, recommend, or merge them.
- `AI_INDEX-original.md` describes a `modules/` layout that never existed
  in this repository. Its file paths are not real.
- `registry-schema.json` describes an older, incompatible record model.
  The active contract is `index/resource-schema.json`.

These files are kept only as provenance for how the repository evolved.
The canonical catalog is `resources.json`; the AI-optimized views are in
`index/resources.compact.json` and `index/by-category/`.
